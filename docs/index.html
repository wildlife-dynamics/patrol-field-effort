Patrol Field Effort Workflow

Analyzes ranger patrol activity within a study area and produces a dashboard summarizing field effort across three spatial metrics, sourced live from EarthRanger.

What it produces

  • A Days Since Last Patrol Visit map (5-class grid)
  • A Dwell Time (Hours) map (5-class grid)
  • A Linear Time Density map (5-class grid, patrol route coverage)
  • Three stat cards — total patrols, total distance (km), patrol coverage (%)
  • An operational days table — distance, duration, and patrol days per ranger
  • An interactive widget dashboard combining all of the above

Requirements

  • Access to an EarthRanger instance with completed (done) patrols recorded in the analysis period
  • An area-of-interest feature layer available via EarthRanger's spatial features

Groupers are fixed to an empty list for this workflow — every output covers the whole dataset as a single combined view; there is no per-group breakdown.

Get started

New to the workflow? Start with the User Guide for a walkthrough of loading the template and configuring the time range, area of interest, grid cell size, and base maps. Running into an error? Check Troubleshooting first.
