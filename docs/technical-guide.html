Technical Guide

A deeper look at how the Patrol Field Effort Workflow is built: the EarthRanger ingestion pipeline, grid construction, field-effort metric methodology, classification/styling, and dashboard assembly.

Download the full Technical Guide (PDF)

This guide was written directly from spec.yaml. Two behaviours worth calling out up front: groupers are fixed to an empty list (no per-group breakdown is possible in this workflow), and the patrol fetch uses raise_on_empty: true, so a time range or area of interest with no completed patrols fails the run rather than producing a partially-empty dashboard.
